# 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/shobhitasthana1/asthana-studio.git
```

### Move into the Project

```bash
cd asthana-studio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
